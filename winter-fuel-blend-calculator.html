Model details & assumptions
  • Current tank blend:
    The current mix slider represents the percentage of #2 fuel already in the tank. The #1 percentage is calculated as the remainder: #1% = 100% − #2%.
  • Target blend:
    The target slider represents the desired percentage of #2 fuel after adding #1. The target #1 percentage is calculated as the remainder. The calculator assumes that only straight #1 fuel is being added.
  • When the target is out of range:
    If the current tank already contains a greater percentage of #1 than the selected target, the target cannot be reached by adding more #1. The mix sliders or tank values must be adjusted.
  • Gallons of #1 required:
    The amount of #1 to add is calculated from the current gallons, current #2 fraction, and target #2 fraction:
    #1 to add = (current #2 gallons − target #2 fraction × current gallons) ÷ target #2 fraction .
  • Total gallons after blending:
    The resulting total is the current tank gallons plus the calculated gallons of #1 to add.
  • Tank capacity:
    When a tank size is entered, remaining capacity is calculated after adding the required #1 fuel. If the resulting total exceeds the tank size, the calculator displays Over Capacity. Cold-flow additive volume is not included in this capacity check.
  • Cloud-point blend model:
    Cloud point is estimated with a nonlinear empirical blend curve derived from normalized Minnesota and Iowa #1/#2 diesel blend-test data. For x equal to the #1 fraction:
    F(x) = 0.6x − 0.8x² + 1.2x³
    Blend CP = CP₂ + (CP₁ − CP₂) × F(x). The rounded coefficients closely match the more precise fitted curve while being easier to document and maintain.
  • Current estimated cloud point:
    The current tank estimate uses the nonlinear blend model with the current-card #1 and #2 cloud-point settings and the current tank mix.
  • Projected cloud point:
    The projected value beside the target slider uses the same nonlinear model with the selected target ratio, the target-card #1 cloud point, and the current-card #2 cloud point.
  • Final estimated cloud point:
    The final result uses the actual calculated #1 fraction after the new #1 is added, then applies the same nonlinear model. If the current tank's #1 cloud-point setting differs from the added #1 cloud-point setting, those two #1 endpoints are volume-weighted across the #1 gallons before the nonlinear #1/#2 curve is applied.
  • Default fuel assumptions:
    The default #2 cloud point is 14°F, intended to represent the summer #2 heel normally present when winter blending begins. The default #1 cloud point is -55°F, close to the neat-#1 values measured in the Minnesota and Iowa test data used to develop the curve. Actual fuel can vary substantially, so the advanced cloud-point values should be replaced with supplier specifications or test data when known.
  • Model-data limitation:
    The Minnesota and Iowa blend tests used #2 fuels with cloud points around +2°F to +3°F, not a +14°F summer #2 sample. The curve was normalized to the neat-fuel endpoints before fitting, so using it with a +14°F summer #2 endpoint is an empirical extrapolation rather than a direct laboratory test of that exact fuel pair.
  • Cold-flow dose:
    When cold flow is enabled, the required additive amount is calculated from the total gallons after blending:
    Cold-flow ounces = total gallons × dose in oz per 100 gal ÷ 100 .
  • Cold-flow effect:
    The entered cold-flow effect is based on the default dose of 16 oz per 100 gal. If the dose is changed, the assumed temperature improvement is scaled proportionally:
    Applied effect = entered effect × entered dose ÷ 16 . This adjustment is applied to estimated operability, not to the estimated cloud point.
  • Estimated operability:
    When cold flow is enabled, operability is estimated by subtracting the applied cold-flow effect from the estimated cloud point:
    Operability = cloud point − applied cold-flow effect . When cold flow is disabled, estimated operability equals the estimated cloud point. This is a planning estimate of usable low-temperature performance and is not a measured or standardized CFPP result.
  • Data basis:
    The nonlinear curve is based on petroleum-diesel blend behavior reported in Minnesota state cold-weather testing and Iowa/Upper Midwest fuel-testing work. Those datasets showed that a 50/50 #1/#2 blend does not fall halfway between the neat #1 and neat #2 cloud points, and that the cloud-point drop becomes steeper as #1 becomes the dominant part of the blend.
